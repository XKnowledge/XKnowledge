# XKnowledge v2.6.0 更新说明

发布日期：2026-10-10（对照 tag `v2.6.0`，上一版本 [v2.5.0](https://github.com/XKnowledge/XKnowledge/releases/tag/v2.5.0)）。

## 新增功能

- **新手教程**：首次进入图表页自动开启 9 步遮罩引导（欢迎/菜单/工具栏/双击建点/Ctrl 拖连线/画布导航/图例/属性面板/收尾），看过或跳过即不再自动弹出，菜单可随时重开。（dbdedea）
- **建图可见入口三件套**：工具栏新增「创建节点」按钮，菜单补「创建节点」项；空图时画布中央显示引导提示；选中节点后底部导航条提示连线手势——建点/连线不再只有手势一条暗道，建点入口三扇门（菜单/工具栏/画布双击）走同一条就地编辑器管道。（d175e0b、0711b1e）
- **视频录制期间图谱只读锁定**：环绕动画与导出录屏进行中，修改操作（建/删/粘贴/撤销重做/导入/换文件/设置/教程）与侧栏开合、窗口缩放全部禁用，窗口尺寸焊死；保存、浏览、导航等非修改操作照常——「你的操作不再被录进画面」。（dd305ae）

## 问题修复

- 侧栏开着直接开录，录制画面右缘被裁剪——开录前等待画布缓冲尺寸稳定再定录制区域；录制中编码器失败等异常不再导致窗口永久冻结与录制锁泄漏（收尾改 try/finally）。（0f19c48）
- 渲染进程崩溃后窗口冻结在空白态、只能任务栏/Alt+F4 关闭——崩溃即清理录制锁恢复窗口。（3af8a8f）
- 最大化后「向下还原」按钮误用复制图标，观感像复制按钮——换自绘 Windows 双叠框标准形态。（5b7f3e6）
- 教程遮罩贴边锚点触发 SVG 负值报错、污染控制台。（15a4cf9）
- 2026-10-08 全量审计 21 条缺陷修复（两批 TDD 修复，正常路径行为零变更）与评审 Minor 小修批。（5aef7e1、4300dac）

## 其他

- Electron 44.3.0 → 44.7.0。（58dd9bc）
- 用户手册任务导向重构、新增开发指南 `docs/development.md`，全仓文档段落展开为一段一行。（cdc5678、e7e0e16）
- 内部重构（功能零改变）：ChartView 拆分为 7 个 composables、xkContext 中枢退役为 useDocument 文档域、renderer utils/store 迁移 TypeScript、菜单动作分发统一 `dispatch(action)` 唯一入口。
- 测试补齐：单测基线 484 → 609 用例（40 文件），冒烟脚本既有基线红全数修复，eslint 全仓 0 error。
