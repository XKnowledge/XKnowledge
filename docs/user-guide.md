# XKnowledge 使用说明

XKnowledge 是一款桌面知识图谱软件：用 3D 力导向图组织和展示知识，节点代表概念，
连接代表关系，类目用颜色区分。图谱保存为 `.xk` 文件（JSON 格式），可导出为 PNG 图片。

## 1. 安装与启动

### 使用安装包

从 `release/` 目录（或发布渠道）获取对应平台的安装包。Windows 安装包为向导式：
依次确认许可协议（勾选接受）→ 选择为当前用户还是所有用户安装 → 选择安装目录 →
选择是否创建桌面/开始菜单快捷方式，随后完成安装。

### 从源码运行

需要 Node.js 与 yarn：

```bash
yarn install     # 安装依赖
yarn dev         # 开发模式启动（自动打开 DevTools）
```

> 提示：请全程使用 yarn，不要与 npm 混用，否则可能静默丢失依赖。

## 2. 界面总览

### 首页（启动后）

- 中间是**示例图库**：示例卡片按标题拼音 A→Z 排列；首卡「新建空白文件」单击即进入
  空白图表页；双击任一示例卡片装载该示例图谱（以副本编辑，首次保存弹另存为）。
- 顶部**搜索框**：按标题 / 描述 / 分类过滤示例。
- 左下角「**打开本地文件**」按钮：选择并打开磁盘上的 `.xk` 文件；上方「**设置**」
  按钮打开设置弹窗（主题切换，见 4.7）。

### 图表页（编辑视图）

```
┌──┬────────────────────────────── 未保存（修改后出现）──────┐
│菜│  创建节点  删除节点  创建连接  删除连接  编辑框（工具栏）  │
│单├──────────────────────────────────────────┬─────────────┤
│  │                                          │  侧边栏      │
│图 │            3D 力导向图画布               │  属性面板 /  │
│例 │   左键旋转 · 滚轮缩放 · 右键平移          │  节点·连接表单│
│  │                                          │             │
└──┴──────────────────────────────────────────┴─────────────┘
```

- **左上角菜单**：文件操作（新建、打开、关闭、保存、另存为）与编辑操作（撤销、
  重做、增删节点/连接）。
- **工具栏**：创建节点、删除节点、创建连接、删除连接、编辑框（展开/收起侧边栏）。
- **图例**（画布左上）：每个类目一个色点，点击可切换该类目节点的显示/隐藏，
  两端节点任一隐藏时，相应连接一并隐藏。
- **侧边栏**：属性面板（渲染设置）与节点/连接编辑表单交替出现。
- 左上角菜单底部「**设置**」：打开设置弹窗（主题切换，见 4.7）。

## 3. 快速上手

三分钟创建第一张图谱：

1. 启动后在首页**单击「新建空白文件」卡片**（或双击示例图谱；图表页左上角菜单 →
   新建文件，会开一个新窗口）。
2. 工具栏点「**创建节点**」（或按 `Insert`），在侧边栏填写名称、描述，选择或新增
   类目，点「创建节点」。
3. 在画布中**依次点击两个节点**（会高亮为橙色，至多保留最近两个），再点「**创建
   连接**」，填写连接名称后提交。
4. 重复 2–3 步扩充图谱；用「排斥力」滑杆调整节点间疏密，滚轮缩放到满意为止。
5. `Ctrl+S` 保存（首次会弹出另存为对话框，选择保存位置，文件后缀 `.xk`）。
6. 需要插图时，侧边栏属性面板点「**导出图片**」，得到带「By XKnowledge」水印的 PNG。

## 4. 功能详解

### 4.1 文件操作

| 操作 | 入口 | 行为 |
| --- | --- | --- |
| 新建文件 | 图表页菜单 → 新建文件 | **新窗口**装载空白图谱；未保存前关闭会提示 |
| 打开文件 | 首页「打开本地文件」/ 图表页菜单 → 打开文件 | 首页打开为同窗口跳转；图表页中打开为**新窗口**，保存直接写回原文件 |
| 保存 | `Ctrl+S` / 菜单 → 保存 | 有路径直接写回；未存盘的新建文件与示例副本首次保存弹另存为 |
| 另存为 | 菜单 → 另存为... | 另存后新路径成为当前文件，旧文件不受影响 |
| 关闭文件 | 菜单 → 关闭文件 | 关闭当前文件并回到首页；有未保存修改时弹确认：**保存 / 放弃 / 取消**；窗口恢复默认尺寸 |
| 自动保存 | — | 有未保存修改且已有文件路径时，每 60 秒自动保存一次 |
| 关闭窗口 | 窗口 X | 有未保存修改时弹确认：**保存 / 放弃 / 取消** |

打开与去重的细节：

- 同一个文件已在某个窗口打开时，不会重复开窗，而是**置前那个窗口**并提示
  「该文件已在打开的窗口中」。
- 窗口标题显示当前文件名（未保存显示「未命名」）；多个窗口打开同名文件时，
  标题自动补上级目录区分（如「金融 — 资料」）。
- 文件损坏（非法 JSON、缺少 nodes/links、连接引用了不存在的节点）会在打开时被
  拦截并提示，不会进入编辑。
- 若文件在打开后被**其他窗口或外部程序**修改，保存会提示冲突，请使用「另存为」
  保留你的修改；冲突解决前自动保存暂停。

### 4.2 编辑节点

| 操作 | 做法 |
| --- | --- |
| 创建 | 工具栏/菜单「创建节点」或 `Insert` → 填表提交 |
| 查看/修改 | 点击画布中的节点 → 侧边栏出现表单，改完点「修改节点」 |
| 删除 | 选中节点后，工具栏/菜单「删除节点」或 `Delete`（最后点击的是节点时）；**与它相连的连接一并删除** |
| 改名 | 修改表单中改名即可，所有相连连接的指向自动跟随 |

节点字段：

- **名称**：全图唯一（主键），创建同名节点会被拒绝。
- **描述**：悬浮在节点上时显示为「名称：描述」。
- **所属类目**：决定颜色（同名类目永远同色）；下拉框底部可**即时新增类目**。
- **节点大小**：1–100，决定球体大小。

### 4.3 编辑连接

| 操作 | 做法 |
| --- | --- |
| 创建 | 依次点击**恰好两个节点**（橙色高亮）→「创建连接」→ 填名称提交 |
| 查看/修改 | 点击画布中的连接 → 侧边栏表单，改完点「修改连接」 |
| 删除 | 选中连接后，工具栏/菜单「删除连接」，或 `Delete`（最后点击的是连接时） |

约束：两点之间只允许一条连接（不分方向）；未选中 2 个节点时提交会提示
「请选中2个节点」。

### 4.4 撤销与重做

`Ctrl+Z` 撤销、`Ctrl+Y` 重做（也可从左上角菜单触发）。覆盖全部六类操作：节点/连接的
创建、删除、修改（含删除节点时连带删除的连接）。撤销后进行新操作，其后被放弃的
重做分支自动失效。历史不落盘，关闭窗口即清空。

### 4.5 视图与渲染（属性面板）

侧边栏属性面板（点工具栏「编辑栏」展开）：

| 设置 | 说明 |
| --- | --- |
| 悬浮显示连接名称 | 鼠标悬停在连接上时显示连接名 |
| 显示小节点名称 | 关闭后仅 symbolSize 最大的前 30 个节点常显名称，图更清爽；默认开启全显 |
| 聚焦模式 | 勾选后点亮焦点节点「跳数」内的邻域网络，其余节点与连接退为浅灰背景；开启后单击任意节点即切换焦点，取消勾选恢复全图。适合大图里只看局部、不被整体密度干扰 |
| 跳数 | 聚焦的邻域半径，1–3 可选，默认 2。注意 3 跳在大图上可能覆盖整个连通分量，重新变成看纹理 |
| 排斥力大小 | 1–500，越大节点相互推开越远，用于缓解密集拥挤 |
| 图谱简介 | 编辑当前图谱的简介文字，随 `Ctrl+S` / 自动保存写入 `.xk` 文件（见下方说明） |
| 导出图片 | 导出当前视图为 PNG（含「By XKnowledge」水印，画布上不显示水印） |
| 复位视图 | 相机归位并自动取景全图 |

除图谱简介外，视图设置是**会话级**的：不会写入 `.xk` 文件，重新打开文件后恢复
默认值。图谱简介则会保存进 `.xk` 文件，首页图库卡片的简介文字即来自这里。
聚焦模式同样是会话级，但**跨文件保持**：切换文件后仍保持开启，并自动聚焦到
新图中连接数最多的节点（并列取 symbolSize 更大的，再并列取先出现的）——大图
打开的第一眼就是可读的局部网络，而不是一片纹理。

### 4.6 3D 画布操作

| 手势 | 效果 |
| --- | --- |
| 左键拖拽 | 旋转视角 |
| 滚轮 / 中键 | 缩放 |
| 右键拖拽 | 平移 |
| 单击节点 / 连接 | 选中（橙色高亮）并在侧边栏打开对应表单；节点高亮最多保留最近 2 个 |

画布底部有操作提示文案。首次打开文件、布局稳定后会自动取景一次；之后的编辑不会
打扰当前视角。

### 4.7 主题切换

设置弹窗（首页左下角「设置」按钮、图表页左上角菜单底部「设置」）中的「主题」
三选一：

- **跟随系统**：随 Windows 系统主题自动切换，系统改动实时生效
- **浅色 / 深色**：强制固定，不随系统变化

选择即时生效、会被记住，下次启动保持；同时打开多个窗口时，在任一窗口切换，
其余窗口同步跟随。深色模式下 3D 图谱的背景、连线、标签与高亮配色整体配套切换；
导出图片的水印颜色跟随当前主题背景（导出即所见）。

## 5. 快捷键一览

| 快捷键 | 动作 | 备注 |
| --- | --- | --- |
| `Ctrl+S` | 保存 | |
| `Ctrl+Z` | 撤销 | 焦点在输入框时不触发 |
| `Ctrl+Y` | 重做 | 焦点在输入框时不触发 |
| `Insert` | 创建节点 | 焦点在输入框时不触发 |
| `Delete` | 删除节点/连接 | 删除**最后点击**的对象（点击另一方时旧的选中态作废）；焦点在输入框时不触发 |
| `Ctrl+R` / `F5` | 刷新 | **被禁用**（刷新会丢失未装载完的图表数据） |

## 6. `.xk` 文件格式

`.xk` 是 UTF-8 编码的 JSON，结构如下：

```json
{
  "version": 2,
  "nodes": [
    { "name": "GDP", "des": "…", "symbolSize": 50, "category": "宏观经济" }
  ],
  "links": [
    { "source": "GDP", "target": "CPI", "name": "传导", "des": "…" }
  ]
}
```

- 节点以 `name` 为唯一标识；`links` 的 `source`/`target` 引用节点名。
- 手工编辑后若 JSON 非法或连接悬空，文件会被判定损坏而无法打开，修改前建议先备份。
- `examples/金融.xk` 是一份金融学习示例图谱，可直接打开体验。

## 7. 常见问题

**打开文件提示「文件已损坏或不是有效的 XKnowledge 文件」**
JSON 语法错误，或不是 v2 结构（缺少 `version: 2` / `nodes` / `links`）。可手动修复
JSON 后重试；早期（v1）格式的旧文件不再支持。

**打开文件提示「文件结构不完整…」**
括号里会注明缺失项，常见为连接引用了不存在的节点名（悬空连接），补齐节点或删掉
该连接即可。

**保存时提示「文件已被其他窗口或外部程序修改」**
文件在别处被改过，直接覆盖会丢失对方的修改。请用「另存为」换一个路径保存；
在此之前自动保存已暂停，不会反复弹错。

**3D 视图初始化失败（显卡驱动异常？）**
WebGL 不可用。侧边栏的编辑、保存功能不受影响，可正常使用；建议更新显卡驱动后重启
应用。

**保存目录里出现 `.tmp-` 开头的文件**
自动保存采用「临时文件 + 改名」的原子写入，应用崩溃时机不巧可能留下残件，确认文件
本身正常后可手动删除。

**提示「该文件已在打开的窗口中」**
同一文件已在某窗口编辑，应用会自动置前那个窗口，避免两个窗口互相覆盖。
