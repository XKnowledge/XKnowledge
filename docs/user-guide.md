# XKnowledge 用户手册

XKnowledge 是一款桌面知识图谱软件：用 3D 力导向图（连线把相关概念拉近、节点之间相互排斥，排斥力大小可调，图会自动「摊开」成稳定布局）组织和展示知识，节点代表概念，连接代表关系，类目用颜色区分。图谱保存为 `.xk` 文件（JSON 格式），可导出为带水印的 PNG 图片。

本手册面向最终用户，**按你想做的事分章**：装好上手见第 1 章；认识界面见第 2 章；建图改图见第 3 章；查看与定位大图见第 4 章；保存、打开与多窗口见第 5 章；把图分享给别人见第 6 章；主题、语言、快捷键等个性化见第 7 章；遇到问题先查第 8 章常见问题；快捷键表与 `.xk` 格式细节收在附录。从源码运行软件的方式见 [开发指南](./development.md)。

## 1. 开始使用

### 1.1 安装

从 `release/` 目录（或发布渠道）获取对应平台的安装包。以 Windows 为例，安装包为向导式：依次确认许可协议（勾选接受）→ 选择为当前用户还是所有用户安装 → 选择安装目录 → 选择是否创建桌面/开始菜单快捷方式，随后完成安装。

### 1.2 启动行为

应用采用**单实例**设计：已经运行时再次启动不会出现第二个实例。图表数据在窗口间不共享，多窗口各自独立编辑不同文件。

### 1.3 三分钟建第一张图

1. 启动后在首页**单击「新建空白文件」卡片**（或双击任一示例图谱；图表页左上角菜单 → 新建文件，会开一个新窗口）。
2. 在画布空白处**双击**，就地输入节点名称，回车后类目下拉（向上展开）中选定已有类目或即时新增一个——选定即建成，不用碰任何表单，像打字一样连续建图。需要非默认大小时，下一行选 小/中/大 档位（默认中）或在数框直接填自定义值（1~100）；想留备注，末行描述框（可选，可拖角拉伸）填一句即可。
3. **按住 `Ctrl`（macOS 为 `⌘`）把一个节点拖到另一个节点上松开**，就地输入连接名称（留空则建无名边），回车建成；拖到空白处松开即放弃。
4. 重复 2–3 步扩充图谱；用「排斥力」滑杆调整节点间疏密，滚轮缩放到满意为止。图大了以后可用 `Ctrl/⌘+F` 搜索定位节点（见 4.3）。
5. `Ctrl/⌘+S` 保存（首次会弹出另存为对话框，选择保存位置，文件后缀 `.xk`）。
6. 需要插图时，左上角菜单 →「**导出**」→「**导出图片**」，得到带「By XKnowledge」水印的 PNG；想要动态展示就用「**环绕录制**」让相机自动环绕一圈录成 MP4，或用「**导出录屏**」录下自己的实时操作（见第 6 章）。

双击建点时就地选定大小档位（小 30/中 50/大 80，默认中）或数框自定义（1~100，同侧栏节点大小）、填可选描述（可多行、拖角拉伸）；建出的节点/连接也可事后点开在侧边栏补全或修改描述等字段（见 3.1）。

手头已有大纲式材料（笔记、文档目录）时，不必从空图搭起：菜单 →「**从大纲导入...**」粘贴文本即可生成初图，再手工修缮（见 3.5）。

## 2. 界面一览

### 2.1 首页（示例图库）

- **示例图库**：内置 200 余张示例图谱（随版本增减），卡片按标题拼音 A→Z 排列。每张卡片包含：标题、类目色点（最多 18 个，超出收进「+N」点，悬停可看全部类目名）、节点数 · 连接数、图谱简介（两行截断）。卡片上的色点与打开后图内的类目配色完全一致。
- **首卡「新建空白文件」**（虚线框）：单击即进入空白图表页；搜索过滤时该卡片隐藏（此时意图是找示例）。
- **示例卡片**：单击选中（描边高亮），**双击打开**——以副本编辑，首次保存弹「另存为」（内置示例永不会被改写，见 5.5）。
- **顶部搜索框**：按标题 / 描述 / 分类过滤示例，子串匹配、大小写不敏感。
- **左下角按钮**：「设置」打开设置弹窗（主题切换见 7.1、语言切换见 7.2）；「打开本地文件」选择并打开磁盘上的 `.xk` 文件（同窗口进入图表页）。

首页窗口为固定尺寸 900×670，不可调整、最大化或最小化。

### 2.2 图表页（编辑视图）

```
┌──┬────────────────────────────── 未保存（修改后出现）──────┐
│菜│  创建节点  删除节点  删除连接  编辑栏（工具栏）        │
│单├──────────────────────────────────────────┬─────────────┤
│  │ 图例                    [图内搜索 Ctrl+F] │  侧边栏      │
│  │                                          │  属性面板 /  │
│图 │            3D 力导向图画布               │  节点·连接表单│
│例 │   左键旋转 · 滚轮缩放 · 右键平移          │             │
│  │                                          │             │
└──┴──────────────────────────────────────────┴─────────────┘
```

- **左上角菜单**（点击图标展开），从上到下依次为：新建文件、打开文件、关闭文件；撤销（`Ctrl/⌘+Z`）、重做（`Ctrl/⌘+Y`）、创建节点（与画布双击/工具栏按钮同链，中心落点）、删除节点（`Delete`）、删除连接；保存（`Ctrl/⌘+S`）、另存为...；**导出**（子菜单：导出图片 / 导出 HTML / 环绕录制 / 导出录屏，见第 6 章）；从大纲导入...；设置。菜单中的快捷键标注跟随用户自定义实时显示（默认值见附录 A）。
- **工具栏**：创建节点（与画布双击同一条就地编辑链）、删除节点、删除连接、编辑栏（展开/收起侧边栏）。侧边栏收起后点击画布中的节点/连接会自动唤起侧边栏。
- **图例**（画布左上角，工具栏下方）：每个类目一个色点，点击可切换该类目节点的显示/隐藏；隐藏的类目显示为删除线 + 半透明。两端节点任一类目隐藏时，相应连接一并隐藏。图例可与图内搜索联动（见 4.3）。
- **画布直操**：双击画布空白处直接建节点（空图时画布中央有引导提示，建成首节点即退场）；直接拖动节点可移动位置（仅当次会话内有效，不落盘）；按住 `Ctrl`（macOS 为 `⌘`）把一个节点拖到另一个节点上松开即连线——选中节点时底部导航条会显示连线手势提示（详见 3.1 / 3.2）。
- **侧边栏**（约 270px）：属性面板（渲染设置）与节点/连接编辑表单交替出现。

进入图表页后窗口解锁：可自由调整尺寸（最小 900×670）、可最大化/最小化。关闭文件回到首页时，窗口恢复固定尺寸。

### 2.3 窗口标题与未保存标记

- 窗口标题显示当前文件名（未保存时显示「未命名」）。应用内标题条与任务栏/Alt-Tab 双位置显示，未保存修改时两处都会出现圆点标记：标题条为「文件名 • — XKnowledge」，任务栏为「• 文件名 — XKnowledge」。
- 多个窗口打开同名文件时，标题自动补上级目录区分（如「金融 — 资料」）；仍冲突时逐级加深目录链，直到可区分。冲突解除后自动恢复短名。
- 圆点是唯一的未保存提示：出现圆点即表示有尚未写盘的修改。

## 3. 编辑图谱

本章解决「怎么把知识装进图里」：单个节点与连接的增删改、用类目组织、误操作的撤销，以及从现成大纲批量建图。

### 3.1 创建与编辑节点

| 操作      | 做法                                                                                                                                                                                                                   |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 创建      | **画布直操**：双击画布空白处（或点工具栏「创建节点」，以画布中心为落点），就地三行建点——名称+类目（下拉向上展开，选定即建成）/ 大小档位 小/中/大（默认中，映射 30/50/80）或数框自定义 1~100 / 可选描述（可多行、拖角拉伸）。描述等字段也可事后点开节点在侧边栏补全 |
| 查看/修改 | 点击画布中的节点 → 侧边栏出现表单，改完点「修改节点」                                                                                                                                                                  |
| 删除      | 选中节点后，工具栏/菜单「删除节点」或 `Delete`（最后点击的是节点时）；**与它相连的连接一并删除**                                                                                                                       |
| 改名      | 修改表单中改名即可，所有相连连接的指向自动跟随                                                                                                                                                                         |

节点字段：

- **名称**：全图唯一，是连接定位节点的依据；创建或改名成与现有节点重名会被拒绝（「不能创建同名节点」）。
- **描述**：悬浮在节点上时显示为「名称：描述」。
- **所属类目**：决定颜色（同名类目永远同色，规则见 3.3）；下拉框底部可**即时新增类目**；未选择类目提交会被拒绝（「请选择/创建节点所属类目」）。
- **节点大小**：1–100，决定球体大小（半径与该值成正比）。

### 3.2 创建与编辑连接

| 操作      | 做法                                                                                                                                                        |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 创建      | **画布直操**：按住 `Ctrl`（macOS 为 `⌘`）把一个节点拖到另一个节点上松开，就地输入连接名称（留空则建无名边），回车建成；描述等字段可事后点开连接在侧边栏补全 |
| 查看/修改 | 点击画布中的连接 → 侧边栏表单，改完点「修改连接」                                                                                                           |
| 删除      | 选中连接后，工具栏/菜单「删除连接」，或 `Delete`（最后点击的是连接时）                                                                                      |

约束与细节：

- **画布直操的取消**：`Ctrl`（macOS 为 `⌘`）拖拽中途松开在空白处（或原节点）即放弃此次连线；拖拽过程中按 `Esc` 无效——`Esc` 只在松开后的输名阶段有效，按下即取消建连。
- 两点之间只允许创建一条连接（不分方向），重复创建提示「两个节点间连接已存在」。
- **例外**：`.xk` 文件格式本身允许同一对节点存在多条连接（部分内置示例自带这种形态），打开、编辑、撤销/重做均正常处理；只是界面上不允许再新建重复连接。

### 3.3 类目与颜色

- 类目色由 20 色调色板按**名称哈希 + 顺延占位**分配：同一套类目集合永远得到同一分配（保存重开、多窗口一致），同名类目永远同色；类目数不超过 20 时保证零撞色。
- 颜色是展示层推导的，不写入 `.xk` 文件。
- 新增类目可能使顺延链重排、**其他已有类目换色**，属预期行为；删除全部同类节点后该类目从图例消失。
- 图例（画布左上角）点击切换类目显隐，隐藏的类目显示为删除线 + 半透明；两端节点任一隐藏时，相应连接一并隐藏。

### 3.4 撤销与重做

`Ctrl/⌘+Z` 撤销、`Ctrl/⌘+Y` 重做（也可从左上角菜单触发）。覆盖全部六类操作：节点/连接的创建、删除、修改（含删除节点时连带删除的连接），画布直操的建点与连边、大纲导入的整批追加（见 3.5）同样进入撤销栈。撤销后进行新操作，其后被放弃的重做分支自动失效。多条同名连接的图上，撤销/重做按「端点 + 连接名」精确定位，不会误伤相邻连接。

历史不落盘：关闭窗口即清空，重新打开文件无法撤销上一次会话的操作。

### 3.5 从大纲导入

图表页左上角菜单 → **从大纲导入...**：把现成的大纲文本（笔记、文档目录、书摘结构）粘贴进弹窗，按规则解析为图谱**追加**到当前文件——适合从已有文字材料快速生成初图再手工修缮，不必从空图搭起。

解析规则（弹窗内有同样的速览提示）：

| 写法                                                        | 解析为                                                                   |
| ----------------------------------------------------------- | ------------------------------------------------------------------------ |
| `#`～`######` 标题                                          | 节点，`#` 数量决定层级；**一级标题同时是类目名**，其节点更大             |
| 缩进列表（`-` `*` `+` `1.`，每 2 空格或 1 个 tab 缩进一档） | 节点，挂在上层节点下                                                     |
| `[[双链]]`                                                  | 显式连接：目标不存在则新建节点（归入「未分类」类目），与所在行的节点连边 |
| 结构行下方的段落文本                                        | 上方最近节点的描述（`[[…]]` 标记剥去后并入，跨空行续接）                 |

行为细节：

- **父子挂靠**：每个节点连到层级比它浅的最近上层节点，层级跳级也能安全挂靠。
- **多个一级标题依次连成链**：`# 数学`、`# 物理` 这样的多根大纲，后一个根挂到前一个根上，整张图保持连通、不散成孤岛。
- **追加合并**：导入的是当前图的增量——**同名节点跳过**（不重建也不覆盖描述），两端节点都在图内且不重复的连接仍会补建；完全没有增量时提示「没有可导入的内容（节点均已存在且无新连接）」。
- **实时预览**：粘贴后弹窗底部即时显示「将导入 N 个节点、M 条连接」；解析不出任何节点时「导入」按钮禁用。
- **一步撤销**：整批导入计一条历史记录，`Ctrl/⌘+Z` 一次撤销整批（见 3.4）。

## 4. 浏览与定位大图

图小怎么转都行，图大了以后的问题集中在这里：怎么操作视角（4.1）、调渲染参数（4.2）、快速找到某个节点（4.3）、只看局部（4.4）、卡了怎么办（4.5）。

### 4.1 3D 画布操作

| 手势                                    | 效果                                                                                                                                           |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 左键拖拽                                | 旋转视角                                                                                                                                       |
| 滚轮 / 中键                             | 缩放                                                                                                                                           |
| 右键拖拽                                | 平移                                                                                                                                           |
| 双击空白处                              | 就地建节点：输入名称（回车）→ 选/新增类目（下拉向上，选定即建成，见 3.1）；下一行可选大小档位或数框自定义大小（默认中），末行可填描述。工具栏「创建节点」按钮同链（中心落点），空图时画布中央有引导 |
| 拖动节点                                | 移动节点位置（仅当次会话内有效，不随文件保存）                                                                                                 |
| `Ctrl`（macOS 为 `⌘`）+拖节点到另一节点 | 就地建连接：松开后输名回车建成；拖到空白处松开即放弃（见 3.2）                                                                                 |
| `Shift`+拖拽（各平台同键）              | 框选：拖出矩形，框住的节点与相交的连接在松手时集体高亮；再次框选即替换选中集，点空白或单击任意对象取消。选中后按 `Delete` 批量删除（见附录 A） |
| 单击节点                                | 选中并高亮（再点一次取消），侧边栏打开节点表单                                                                                                 |
| 单击连接                                | 选中并高亮（再点一次取消），侧边栏打开连接表单                                                                                                 |
| 单击空白处                              | 取消选中与高亮（侧栏回属性页）                                                                                                                 |

- 画布底部有操作提示文案；鼠标悬停节点显示「名称：描述」，悬停连接显示连接名（需开启「悬浮显示连接名称」）。
- 框选只作用于**可见**对象：类目隐藏、深度聚焦隐藏的节点/连接不参与框选；批量删除时，被选中节点的邻接连接会一并删除（与单个删除一致），一次删除可一步撤销。
- 鼠标手势（双击建点、`Shift`+拖框选、`Ctrl`（macOS 为 `⌘`）+拖建连接）为固定设计，暂不支持自定义；当前绑定可在 **设置 → 鼠标手势** 中查看（见 7.4）。
- 打开文件时做一次初始取景；**布局稳定后不会自动取景**，编辑与布局调整不会打断当前视角。想重新框住全图，点属性面板的「复位视图」。
- 编辑后已布局的节点保持原位（新节点加入不导致全图跳动）。
- 选中态颜色随主题：浅色主题下选中节点/连接显示为黑色，深色主题下为白色；图内搜索命中为金黄色、当前项为深橙红色（见 4.3）。
- 超大图（2000 节点以上）会自动加快布局收敛，减少卡顿等待。

### 4.2 视图与渲染设置

侧边栏属性面板（点工具栏「编辑栏」展开）：

| 设置             | 说明                                                                                                                                                                                                          |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 悬浮显示连接名称 | 鼠标悬停在连接上时显示连接名（默认关闭）                                                                                                                                                                      |
| 显示小节点名称   | 默认开启（全部常显）。关闭后**按大小排序最小的 60% 节点**视为小节点、隐藏其名称，图更清爽。超大图（2000 节点以上）为保流畅改为按预算封顶：无论开关状态只显示最大的约 600～1200 个节点名称，开关只影响预算档位 |
| 排斥力大小       | 1–500（默认 100），越大节点相互推开越远，用于缓解密集拥挤；可拖滑杆或直接输入数字                                                                                                                             |
| 图谱简介         | 编辑当前图谱的简介文字，随保存写入 `.xk` 文件的 `description` 字段；首页图库卡片的简介文字即来自这里                                                                                                          |
| 复位视图         | 相机归位并自动取景全图（环绕录制进行中禁用——复位飞相机+取景会毁掉录制画面）                                                                                                                                   |

除图谱简介外，视图设置是**会话级**的：不会写入 `.xk` 文件，重新打开文件后恢复默认值（聚焦模式是唯一例外，见 4.4）。

### 4.3 图内搜索

`Ctrl/⌘+F` 打开图表页右上角的搜索框（任何输入框聚焦时按 `Ctrl/⌘+F` 也会跳到搜索框，遵循浏览器惯例）：

- **匹配范围**：节点名称 + 描述，子串匹配、大小写不敏感。
- **导航**：`Enter` / `↓` 跳到下一个命中，`↑` 上一个，`Esc` 或点击 ✕ 关闭；也可直接点击列表项跳转。关闭搜索同时清除命中高亮，但相机留在原地。
- **高亮**：命中的节点整体标为金黄色，当前项为深橙红色；导航时相机自动飞向当前项，关闭搜索后相机留在原地。
- **列表**：显示每个命中的色点（类目色）、名称与描述（命中文字标橙），计数显示「当前第几 / 共几个」；命中极多时列表只渲染前 100 条，计数仍显示真实总数。
- **与图例联动**：图例中隐藏的类目不参与搜索；搜索开着时切换图例，命中列表与高亮实时更新。
- **与聚焦模式联动**：「隐藏」聚焦模式下，命中的节点豁免隐藏——找到了就该看见。
- **会话级**：不写盘、不置脏、不进撤销栈；切换文件后自动关闭（旧图的关键词对新图没有意义）。

大图中先搜索再定位，比手动旋转平移快得多。

### 4.4 聚焦模式

属性面板中的「聚焦模式」三态选择，适合在稠密大图里只看局部、不被整体密度干扰：

| 模式 | 效果                                                                       |
| ---- | -------------------------------------------------------------------------- |
| 关闭 | 全图正常显示                                                               |
| 灰化 | 点亮焦点节点「跳数」内的邻域网络，其余节点、连接（连同标签）退为浅灰背景   |
| 隐藏 | 邻域外的节点与连接**直接隐去**，画布只剩子网（图内搜索命中的节点仍会显示） |

- **跳数**：邻域半径，1–3 可选，默认 2。注意 3 跳在大图上可能覆盖整个连通分量（彼此连通成一片的全部节点），重新变成看纹理。
- **焦点选择**：开启时优先聚焦当前选中的节点；没有选中则自动选取「连接数最多的节点」（并列取节点大小更大的，再并列取先出现的）。开启后**单击任意节点即切换焦点**。
- **焦点失效**：焦点节点被删除时自动回退到默认焦点；全图删空则恢复正常显示。
- **相机**：开启时自动取景邻域，关闭时恢复开启前的视角，不会抢走你已调好的构图。
- **跨文件保持**：聚焦模式同样不写盘，但**切换文件后仍保持当前模式**，并自动聚焦到新图的默认焦点——大图打开的第一眼就是可读的局部网络，而不是一片纹理。应用重启后恢复「关闭」默认。

### 4.5 大图卡顿怎么办

图越大渲染与布局开销越高，依次尝试（开销从低到高）：

1. 关闭「显示小节点名称」——超大图（2000 节点以上）还会自动按预算封顶标签数量（见 4.2），这是最直接的一刀；
2. 用图例隐藏暂不关心的类目（见 3.3）；
3. 开启聚焦模式只看局部（见 4.4）；
4. 用 `Ctrl/⌘+F` 搜索定位代替手动旋转平移（见 4.3）。

超大图（2000 节点以上）打开时会自动加快布局收敛，减少初始卡顿等待；卡顿明显时先做第 1 步，多数情况立竿见影。

## 5. 管理文件

本章解决文件的保存、打开、多窗口与各种保护机制。

### 5.1 保存与另存为

| 操作   | 入口                     | 行为                                                       |
| ------ | ------------------------ | ---------------------------------------------------------- |
| 保存   | `Ctrl/⌘+S` / 菜单 → 保存 | 有路径直接写回；未存盘的新建文件与示例副本首次保存弹另存为 |
| 另存为 | 菜单 → 另存为...         | 另存后新路径成为当前文件，旧文件不受影响                   |

- 已有路径的文件每 60 秒**自动保存**一次（见 5.3），不必频繁手动保存。
- 「另存为」也是解决保存冲突的标准手段（见 5.4）。

### 5.2 新建、打开与关闭

| 操作     | 入口                                        | 行为                                                                                   |
| -------- | ------------------------------------------- | -------------------------------------------------------------------------------------- |
| 新建文件 | 图表页菜单 → 新建文件                       | **新窗口**装载空白图谱；未保存前关闭会提示                                             |
| 打开文件 | 首页「打开本地文件」/ 图表页菜单 → 打开文件 | 首页打开为同窗口跳转；图表页中打开为**新窗口**，保存直接写回原文件                     |
| 关闭文件 | 菜单 → 关闭文件                             | 关闭当前文件并回到首页；有未保存修改时弹确认：**保存 / 放弃 / 取消**；窗口恢复固定尺寸 |
| 关闭窗口 | 窗口 X                                      | 有未保存修改时弹确认：**保存 / 放弃 / 取消**；选「保存」时保存成功才关闭               |

打开与去重的细节：

- 同一个文件已在某个窗口打开时，不会重复开窗，而是**置前那个窗口**（最小化时自动还原）并提示「该文件已在打开的窗口中」。
- 若文件在打开后被**其他窗口或外部程序**修改，保存会提示冲突，请使用「另存为」保留你的修改（见 5.4）；冲突解决前自动保存暂停，不会每分钟重复报错。
- 文件损坏（非法 JSON、缺少 version/nodes/links、连接引用了不存在的节点）会在打开时被拦截并提示，不会进入编辑。
- 通过「打开文件」对话框选中安装包内置示例（examples 目录内的文件）时，视同图库打开：走副本语义，保存必弹「另存为」，内置示例永不被写坏（见 5.5）。

### 5.3 自动保存与原子写入

- 有未保存修改且已有文件路径时，每 60 秒自动保存一次，全程静默、不打断编辑。
- 保存采用「临时文件 + 改名」的**原子写入**：写入中途崩溃/断电/磁盘满时，目标文件要么是旧内容、要么是新内容，不会留下截断的半个 JSON。
- 极端情况下保存目录可能出现 `.tmp-` 开头的残件（应用崩溃时机不巧遗留），确认文件本身正常后可手动删除。

### 5.4 外部修改冲突

文件被其他窗口或外部程序（编辑器、同步盘等）修改后，再保存会被拦截并提示「文件已被其他窗口或外部程序修改」——直接覆盖会丢失对方的修改。此时请使用「另存为」换一个路径保存你的版本；冲突解决前自动保存暂停，不会反复弹错。

### 5.5 内置示例写保护

`examples/` 目录内的示例是内置资产，任何途径都不允许写回：

- 图库双击打开的示例走**副本语义**（保存必弹「另存为」，编辑的始终是自己的副本）；
- 通过「打开文件」对话框选中示例文件，同样按副本处理；
- 「另存为」时选择示例目录内的路径会被拒绝（「示例文件不允许修改，请选择其他位置保存」）。

### 5.6 关闭保护

关闭未保存的文件或窗口前，一律弹出三选一确认：**保存 / 放弃 / 取消**。确认框模态于触发它的窗口，多窗口并排时不会误关别的窗口。选择「保存」时只有保存成功才会关闭，失败则留在当前页面。

## 6. 分享与导出

把图给别人看有三种形态：静态插图（6.1）、可交互的单文件网页（6.2）、视频（6.3）；6.4 解决「把别的图的子图搬过来」。四个入口都在图表页左上角菜单的「**导出**」子菜单（复制/粘贴走快捷键）。

### 6.1 导出图片（PNG）

菜单 →「导出」→「导出图片」导出当前视图为 PNG：自动合成「By XKnowledge」水印（位于底部约 5% 处、颜色随主题——浅底黑字/深底白字），画布上不显示水印；文件随后自动保存到系统默认下载目录，文件名形如 `xknowledge-2026-09-24-12-30-00.png`。

### 6.2 导出交互式 HTML（单文件分享）

菜单 →「导出」→「导出 HTML」把当前图谱导出为一个**单文件网页**（.html）：数据与 3D 渲染器全部内嵌在文件里，把它发给任何人——对方双击即可在浏览器中打开，无需安装任何软件。

接收方可以：

- 旋转 / 缩放 / 平移 / 拖动节点，漫游 3D 图谱（打开时节点从散乱聚合成形）；
- 悬停节点 / 连接查看名称与描述；
- 点击节点在右侧面板查看详情（名称、描述、类目、连接数）；
- 顶部搜索框搜索并高亮命中（Enter 在命中之间步进）；
- 左上角**类目卡片**（与软件图例同位）：点击类目显隐过滤；
- 右侧**「视图」卡片**（可展开/收起，点标题行切换）：聚焦模式（关闭 / 灰化 /隐藏，1–3 跳邻域）、小节点名称开关、复位视图；点击节点弹出的详情面板同在右侧栏；
- 深浅色主题切换（初始跟随接收方系统偏好）；界面文案跟随**导出时的应用语言**——中文软件里导出的就是中文界面，English 软件里导出的就是英文界面。

说明：

- 导出的是**只读快照**：接收方的任何操作（拖动、聚焦、显隐）不影响数据，也不会写回 `.xk` 文件；
- 布局为动态成形：打开时力导向重新布局，不携带编辑器中的坐标；
- 导出的网页自带「By XKnowledge」水印（与 PNG 导出一致）；
- 大图（2000+ 节点）导出文件约 1–2MB，主流浏览器均可打开；
- 默认文件名为图谱名（从图库打开的示例用图库名），接收方看到的是完整的交互能力，与编辑器的编辑语义无关。

### 6.3 环绕视频与录屏

两种视频导出都固定 1080p（与窗口大小无关），自动叠加水印（与导出图片同一样式，仅合成进视频），弹出保存框选择位置后落盘；两者互斥，任一录制进行中另一项不可用。

| 导出     | 说明                                                                                                                                                                                                                                                                                                                                                                                                                          |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 环绕录制 | 相机绕图中心自动旋转一圈（10 秒）并录制为视频。录制期间画布输入与视角/布局操作被锁定保证画面纯净，菜单项显示「录制中…」并禁用，按 `Esc` 可中途取消。格式优先 MP4，当前环境不支持时自动改用 WebM。适合无人值守的展示                                                                                                                                                                                                           |
| 导出录屏 | 点击开始录制自己在 3D 画布上的实时操作（旋转/缩放/点选，录制范围只有画布内容，不含侧栏等界面元素）。画布右下角出现**控制卡片**：暂停按钮（暂停后变为继续，暂停期间的内容不计入视频）、红色结束按钮（停止并弹出保存框，在框中点取消即丢弃这段录制）与右侧 ⠿ 拖动手柄（按住手柄才能拖动卡片位置，按卡片其他位置不会拖动）；菜单项同时变红色「停止录屏」，两处都能停止。适合录操作演示；录制期间界面不锁定，你的操作都会被录进去 |

### 6.4 跨文件复制与粘贴

复制走**系统剪贴板**：在一个窗口复制后，内容跨窗口、跨文件可用，窗口关闭甚至应用重启后仍在（在外部文本编辑器里能看到一段带标记的 JSON，属正常现象）。

**复制（`Ctrl/⌘+C`）**——复制哪些对象与删除的三路分发完全一致：

1. 有框选集：框选的节点与连接（框住两个节点没框住中间连线时，互连连线也在子图里——与删除的「连带」对称）；框选连接的端点节点一并带上，复制出的子图总是自洽（粘贴到空文件也不丢边）。
2. 无框选但最后点击的是连接：该连接 + 两端节点。
3. 都没有但最后点击的是节点：节点本身（要连边一起复制请用框选）。

**粘贴（`Ctrl/⌘+V`）**——**合并**语义（与大纲导入一致），不是制造副本：

- 目标图已有同名节点时**跳过该节点**，但引用它的连接仍然接上——相当于把子图「补」进目标图，补上缺的节点和连接。
- 连接按无向端点对去重：目标图已有同名节点对之间的连接时不重复建边；连接端点所引用的节点在目标图（含本次新粘贴的节点）里不存在时，该连接不粘贴。
- 粘贴整批是一条历史记录，`Ctrl/⌘+Z` 一步撤销。
- 粘贴的节点不带源文件的布局坐标，由力导向布局自动摆放融入当前图。

**推论**：在同一文件内复制再粘贴，节点全部同名、连接全部端点对重复，结果必是「没有可粘贴的新内容」——要同文件副本，先把源节点改名再复制。剪贴板里没有本应用的图谱选区（比如普通文本）时，粘贴会提示「剪贴板没有可粘贴的图谱内容」，数据不动。

## 7. 个性化设置

设置弹窗从首页左下角「设置」按钮或图表页左上角菜单底部的「设置」打开。

### 7.1 主题

设置弹窗中的「主题」三选一：

- **跟随系统**：随系统主题自动切换，系统改动实时生效
- **浅色 / 深色**：强制固定，不随系统变化

选择即时生效、会被记住，下次启动保持。同时打开多个窗口时，在任一窗口切换，其余窗口同步跟随。深色模式下 3D 图谱的背景、连线、标签与高亮配色整体配套切换，窗口原生标题栏颜色同步；导出图片的水印颜色跟随当前主题（导出即所见）。

### 7.2 语言

设置弹窗中的「语言」三选一：

- **跟随系统**：中文系统显示中文，其他系统显示英文（默认）
- **中文 / English**：强制固定

选择即时生效、会被记住，下次启动保持。多窗口任一切换，其余窗口同步跟随。全部界面文案（菜单、侧栏、提示、对话框、窗口标题）与 antd 组件内置文案（弹窗按钮、空态等）一并切换；大纲导入的默认类目名「未分类」与示例图库内容属数据层，不随语言变化。

### 7.3 快捷键自定义

7 个键盘键位（保存 / 撤销 / 重做 / 删除 / 复制 / 粘贴 / 图内搜索）可在**设置 → 快捷键** 中点击绑定按钮重新录制：

- 与其他键位冲突或系统保留组合会被**拒绝并提示**；
- 录制中按 `Esc` 只取消录制，不关弹窗；
- 改键即时生效，菜单中的快捷键标注跟随实时显示。

默认键位表见附录 A。`Ctrl/⌘+R` / `F5` 是防刷新拦截（刷新会丢失未装载完的图表数据），不属于可自定义键位。键位判定对输入框做了守卫：焦点在输入框时编辑类快捷键不触发，放行系统原生文本操作（复制/粘贴等）。

### 7.4 鼠标手势

三个鼠标手势为**固定设计，暂不支持自定义**，当前绑定可在设置 → 鼠标手势中查看：

| 手势                                    | 动作       |
| --------------------------------------- | ---------- |
| 双击空白处                              | 就地建节点 |
| `Ctrl`（macOS 为 `⌘`）+拖节点到另一节点 | 就地建连接 |
| `Shift`+拖拽                            | 框选       |

平台例外：**建边拖拽** macOS 只认 `⌘`+拖（`Ctrl`+点按在 macOS 是系统右键语义，不承担建边），Windows/Linux 只认 `Ctrl`+拖；**框选拖拽**全平台统一 `Shift`，无平台差异。键盘快捷键没有此差异——两平台主修饰键（`Ctrl` / `⌘`）任一都有效，见附录 A。

## 8. 常见问题

**打开文件提示「文件已损坏或不是有效的 XKnowledge 文件」**JSON 语法错误，或不是 v2 结构（缺少 `version: 2` / `nodes` / `links`）。可手动修复 JSON 后重试；早期（v1）格式的旧文件不再支持。

**打开文件提示「文件结构不完整…」**括号里会注明缺失项，常见为连接引用了不存在的节点名（悬空连接），补齐节点或删掉该连接即可。

**保存时提示「文件已被其他窗口或外部程序修改」**文件在别处被改过，直接覆盖会丢失对方的修改。请用「另存为」换一个路径保存；在此之前自动保存已暂停，不会反复弹错。

**3D 视图初始化失败（显卡驱动异常？）**WebGL 不可用。侧边栏的编辑、保存功能不受影响，可正常使用；建议更新显卡驱动后重启应用。

**保存目录里出现 `.tmp-` 开头的文件**自动保存采用「临时文件 + 改名」的原子写入，应用崩溃时机不巧可能留下残件，确认文件本身正常后可手动删除。

**提示「该文件已在打开的窗口中」**同一文件已在某窗口编辑，应用会自动置前那个窗口（最小化时自动还原），避免两个窗口互相覆盖。

**大图卡顿怎么办**见 4.5——关小节点名称、藏类目、聚焦局部、搜索定位，开销从低到高。

**误关了窗口，还能找回修改吗**撤销/重做历史不落盘，关闭窗口即清空。但分两种情况：文件已有路径且此前有编辑的，自动保存至多间隔 60 秒，未写盘的修改只会是最近一分钟内的——重新打开文件检查；从未保存过的新建文件（无路径）一旦放弃，修改无法找回。

**示例图谱打开后改了内容，保存不进去**内置示例是只读资产，编辑的一直是副本：`Ctrl/⌘+S` 会弹出「另存为」，选一个 examples 目录之外的位置保存即可。

**新建的类目让其他类目变了颜色**类目色按名称哈希在 20 色调色板中顺延分配，类目集合变化可能引起重排，属预期行为；不影响已保存的数据（颜色不写入 `.xk` 文件）。

## 附录 A：快捷键一览

| 快捷键            | 动作          | 备注                                                                                                                     |
| ----------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `Ctrl/⌘+S`        | 保存          |                                                                                                                          |
| `Ctrl/⌘+Z`        | 撤销          | 焦点在输入框时不触发                                                                                                     |
| `Ctrl/⌘+Y`        | 重做          | 焦点在输入框时不触发                                                                                                     |
| `Delete`          | 删除节点/连接 | 有框选集时**批量删除框选项**（一步撤销）；否则删除**最后点击**的对象（点击另一方时旧的选中态作废）；焦点在输入框时不触发 |
| `Ctrl/⌘+C`        | 复制          | 复制对象的选取与删除同款三路分发（框选集优先→直选连接→最后点击节点，见 6.4）；焦点在输入框时不触发（放行系统文本复制）   |
| `Ctrl/⌘+V`        | 粘贴          | 把剪贴板里的图谱选区**合并**进当前图（跨文件可用，语义见 6.4）；焦点在输入框时不触发（放行系统文本粘贴）                 |
| `Ctrl/⌘+F`        | 图内搜索      | 任何位置都触发（包括输入框聚焦时，浏览器惯例）                                                                           |

> **macOS**：上表 `Ctrl/⌘` 表示两个平台各按各的主修饰键（Windows/Linux 用 `Ctrl`，macOS 用 `⌘`），键盘快捷键两键任一都有效。鼠标手势的平台例外见 7.4。

## 附录 B：`.xk` 文件格式

`.xk` 是 UTF-8 编码的 JSON，结构如下：

```json
{
  "version": 2,
  "title": "图谱标题（可选，首页卡片标题；缺省用文件名）",
  "description": "图谱简介（可选，属性面板「图谱简介」编辑的内容）",
  "nodes": [{ "name": "GDP", "des": "…", "symbolSize": 50, "category": "宏观经济" }],
  "links": [{ "source": "GDP", "target": "CPI", "name": "传导", "des": "…" }]
}
```

- 节点以 `name` 为唯一标识；`links` 的 `source`/`target` 引用节点名。
- `symbolSize` 取 1–100；`category` 缺省视为空字符串类目。
- 同一对节点允许多条连接（界面不提供创建入口，手工编辑或内置示例可能携带）。
- 手工编辑后若 JSON 非法、缺少 `version: 2` / `nodes` / `links`、或连接引用了不存在的节点名，文件会被判定损坏而无法打开；修改前建议先备份。
- 早期（v1）格式的旧文件不再支持。
- 内置示例（`examples/` 目录，如 `金融.xk`、`中国哲学.xk` 等 200 余张）可直接打开体验。
