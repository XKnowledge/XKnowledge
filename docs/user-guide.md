# XKnowledge 使用说明

XKnowledge 是一款桌面知识图谱软件：用 3D 力导向图（连线把相关概念拉近、节点之间
相互排斥，排斥力大小可调，图会自动「摊开」成稳定布局）组织和展示知识，节点代表
概念，连接代表关系，类目用颜色区分。图谱保存为 `.xk` 文件（JSON 格式），可导出为
带水印的 PNG 图片。

本说明面向最终用户，覆盖安装、界面、全部功能、快捷键、文件格式与常见问题。

## 1. 安装与启动

### 1.1 使用安装包

从 `release/` 目录（或发布渠道）获取对应平台的安装包。以 Windows 为例，安装包为
向导式：依次确认许可协议（勾选接受）→ 选择为当前用户还是所有用户安装 → 选择安装
目录 → 选择是否创建桌面/开始菜单快捷方式，随后完成安装。

### 1.2 从源码运行

需要 Node.js 与 yarn：

```bash
yarn install     # 安装依赖
yarn dev         # 开发模式启动（自动打开 DevTools）
```

> 提示：请全程使用 yarn，不要与 npm 混用，否则可能静默丢失依赖。国内网络下
> Electron 二进制下载失败时，手动执行 install.js 需显式携带 `ELECTRON_MIRROR`
> 环境变量。

### 1.3 启动行为

应用采用**单实例**设计：已经运行时再次启动不会出现第二个实例。图表数据在窗口间
不共享，多窗口各自独立编辑不同文件。

## 2. 界面总览

### 2.1 首页（示例图库）

- **示例图库**：内置 200 余张示例图谱（随版本增减），卡片按标题拼音 A→Z 排列。
  每张卡片包含：标题、类目色点（最多 18 个，超出收进「+N」点，悬停可看全部类目
  名）、节点数 · 连接数、图谱简介（两行截断）。卡片上的色点与打开后图内的类目
  配色完全一致。
- **首卡「新建空白文件」**（虚线框）：单击即进入空白图表页；搜索过滤时该卡片
  隐藏（此时意图是找示例）。
- **示例卡片**：单击选中（描边高亮），**双击打开**——以副本编辑，首次保存弹
  「另存为」（内置示例永不会被改写，见 7.3）。
- **顶部搜索框**：按标题 / 描述 / 分类过滤示例，子串匹配、大小写不敏感。
- **左下角按钮**：「设置」打开设置弹窗（主题切换，见 4.9）；「打开本地文件」
  选择并打开磁盘上的 `.xk` 文件（同窗口进入图表页）。

首页窗口为固定尺寸 900×670，不可调整、最大化或最小化。

### 2.2 图表页（编辑视图）

```
┌──┬────────────────────────────── 未保存（修改后出现）──────┐
│菜│  创建节点  删除节点  创建连接  删除连接  编辑栏（工具栏）  │
│单├──────────────────────────────────────────┬─────────────┤
│  │ 图例                    [图内搜索 Ctrl+F] │  侧边栏      │
│  │                                          │  属性面板 /  │
│图 │            3D 力导向图画布               │  节点·连接表单│
│例 │   左键旋转 · 滚轮缩放 · 右键平移          │             │
│  │                                          │             │
└──┴──────────────────────────────────────────┴─────────────┘
```

- **左上角菜单**（点击图标展开），从上到下依次为：
  新建文件、打开文件、关闭文件；撤销（`Ctrl+Z`）、重做（`Ctrl+Y`）；创建节点
  （`Insert`）、删除节点（`Delete`）、创建连接、删除连接；保存（`Ctrl+S`）、
  另存为...；设置。
- **工具栏**：创建节点、删除节点、创建连接、删除连接、编辑栏（展开/收起侧边栏）。
  侧边栏收起后点击画布中的节点/连接会自动唤起侧边栏。
- **图例**（画布左上角，工具栏下方）：每个类目一个色点，点击可切换该类目节点的
  显示/隐藏；隐藏的类目显示为删除线 + 半透明。两端节点任一类目隐藏时，相应连接
  一并隐藏。图例可与图内搜索联动（见 4.6）。
- **侧边栏**（约 270px）：属性面板（渲染设置）与节点/连接编辑表单交替出现。

进入图表页后窗口解锁：可自由调整尺寸（最小 900×670）、可最大化/最小化。关闭文件
回到首页时，窗口恢复固定尺寸。

### 2.3 窗口标题与未保存标记

- 窗口标题显示当前文件名（未保存时显示「未命名」）。应用内标题条与任务栏/Alt-Tab
  双位置显示，未保存修改时两处都会出现圆点标记：标题条为「文件名 ● — XKnowledge」，
  任务栏为「● 文件名 — XKnowledge」。
- 多个窗口打开同名文件时，标题自动补上级目录区分（如「金融 — 资料」）；仍冲突时
  逐级加深目录链，直到可区分。冲突解除后自动恢复短名。
- 圆点是唯一的未保存提示：出现圆点即表示有尚未写盘的修改。

## 3. 快速上手

三分钟创建第一张图谱：

1. 启动后在首页**单击「新建空白文件」卡片**（或双击任一示例图谱；图表页左上角
   菜单 → 新建文件，会开一个新窗口）。
2. 工具栏点「**创建节点**」（或按 `Insert`），在侧边栏填写名称、描述，选择或新增
   类目，点「创建节点」。
3. 在画布中**依次点击两个节点**（选中态最多保留最近两个），再点「**创建连接**」，
   填写连接名称后提交。
4. 重复 2–3 步扩充图谱；用「排斥力」滑杆调整节点间疏密，滚轮缩放到满意为止。
   图大了以后可用 `Ctrl+F` 搜索定位节点（见 4.6）。
5. `Ctrl+S` 保存（首次会弹出另存为对话框，选择保存位置，文件后缀 `.xk`）。
6. 需要插图时，侧边栏属性面板点「**导出图片**」，得到带「By XKnowledge」水印的 PNG。

## 4. 功能详解

### 4.1 文件操作

| 操作 | 入口 | 行为 |
| --- | --- | --- |
| 新建文件 | 图表页菜单 → 新建文件 | **新窗口**装载空白图谱；未保存前关闭会提示 |
| 打开文件 | 首页「打开本地文件」/ 图表页菜单 → 打开文件 | 首页打开为同窗口跳转；图表页中打开为**新窗口**，保存直接写回原文件 |
| 保存 | `Ctrl+S` / 菜单 → 保存 | 有路径直接写回；未存盘的新建文件与示例副本首次保存弹另存为 |
| 另存为 | 菜单 → 另存为... | 另存后新路径成为当前文件，旧文件不受影响 |
| 关闭文件 | 菜单 → 关闭文件 | 关闭当前文件并回到首页；有未保存修改时弹确认：**保存 / 放弃 / 取消**；窗口恢复固定尺寸 |
| 自动保存 | — | 有未保存修改且已有文件路径时，每 60 秒自动保存一次（后台静默执行，不打断编辑） |
| 关闭窗口 | 窗口 X | 有未保存修改时弹确认：**保存 / 放弃 / 取消**；选「保存」时保存成功才关闭 |

打开与去重的细节：

- 同一个文件已在某个窗口打开时，不会重复开窗，而是**置前那个窗口**（最小化时
  自动还原）并提示「该文件已在打开的窗口中」。
- 若文件在打开后被**其他窗口或外部程序**修改，保存会提示冲突，请使用「另存为」
  保留你的修改；冲突解决前自动保存暂停，不会每分钟重复报错。
- 文件损坏（非法 JSON、缺少 version/nodes/links、连接引用了不存在的节点）会在
  打开时被拦截并提示，不会进入编辑。
- 通过「打开文件」对话框选中安装包内置示例（examples 目录内的文件）时，视同图库
  打开：走副本语义，保存必弹「另存为」，内置示例永不被写坏。

### 4.2 编辑节点

| 操作 | 做法 |
| --- | --- |
| 创建 | 工具栏/菜单「创建节点」或 `Insert` → 填表提交 |
| 查看/修改 | 点击画布中的节点 → 侧边栏出现表单，改完点「修改节点」 |
| 删除 | 选中节点后，工具栏/菜单「删除节点」或 `Delete`（最后点击的是节点时）；**与它相连的连接一并删除** |
| 改名 | 修改表单中改名即可，所有相连连接的指向自动跟随 |

节点字段：

- **名称**：全图唯一，是连接定位节点的依据；创建或改名成与现有节点重名会被拒绝
  （「不能创建同名节点」）。
- **描述**：悬浮在节点上时显示为「名称：描述」。
- **所属类目**：决定颜色（同名类目永远同色，规则见 4.10）；下拉框底部可**即时
  新增类目**；未选择类目提交会被拒绝（「请选择/创建节点所属类目」）。
- **节点大小**：1–100，决定球体大小（半径与该值成正比）。

### 4.3 编辑连接

| 操作 | 做法 |
| --- | --- |
| 创建 | 依次点击**恰好两个节点** →「创建连接」→ 填名称提交 |
| 查看/修改 | 点击画布中的连接 → 侧边栏表单，改完点「修改连接」 |
| 删除 | 选中连接后，工具栏/菜单「删除连接」，或 `Delete`（最后点击的是连接时） |

约束与细节：

- 未选中 2 个节点时提交会提示「请选中2个节点」；节点选中态最多保留最近点击的
  两个，点击第三个节点时最早的选中态自动让位。
- 两点之间只允许创建一条连接（不分方向），重复创建提示「两个节点间连接已存在」。
- **例外**：`.xk` 文件格式本身允许同一对节点存在多条连接（部分内置示例自带这种
  形态），打开、编辑、撤销/重做均正常处理；只是界面上不允许再新建重复连接。

### 4.4 撤销与重做

`Ctrl+Z` 撤销、`Ctrl+Y` 重做（也可从左上角菜单触发）。覆盖全部六类操作：节点/连接
的创建、删除、修改（含删除节点时连带删除的连接）。撤销后进行新操作，其后被放弃的
重做分支自动失效。多条同名连接的图上，撤销/重做按「端点 + 连接名」精确定位，不会
误伤相邻连接。

历史不落盘：关闭窗口即清空，重新打开文件无法撤销上一次会话的操作。

### 4.5 视图与渲染（属性面板）

侧边栏属性面板（点工具栏「编辑栏」展开）：

| 设置 | 说明 |
| --- | --- |
| 悬浮显示连接名称 | 鼠标悬停在连接上时显示连接名（默认关闭） |
| 显示小节点名称 | 默认开启（全部常显）。关闭后**按大小排序最小的 60% 节点**视为小节点、隐藏其名称，图更清爽。超大图（2000 节点以上）为保流畅改为按预算封顶：无论开关状态只显示最大的约 600～1200 个节点名称，开关只影响预算档位 |
| 排斥力大小 | 1–500（默认 100），越大节点相互推开越远，用于缓解密集拥挤；可拖滑杆或直接输入数字 |
| 图谱简介 | 编辑当前图谱的简介文字，随保存写入 `.xk` 文件的 `description` 字段；首页图库卡片的简介文字即来自这里 |
| 导出图片 | 导出当前视图为 PNG：自动合成「By XKnowledge」水印（位于底部约 5% 处、颜色随主题——浅底黑字/深底白字），画布上不显示水印；文件随后自动保存到系统默认下载目录，文件名形如 `xknowledge-2026-09-24-12-30-00.png` |
| 复位视图 | 相机归位并自动取景全图 |

除图谱简介外，视图设置是**会话级**的：不会写入 `.xk` 文件，重新打开文件后恢复
默认值（聚焦模式是唯一例外，见 4.7）。

### 4.6 图内搜索

`Ctrl+F` 打开图表页右上角的搜索框（任何输入框聚焦时按 `Ctrl+F` 也会跳到搜索框，
遵循浏览器惯例）：

- **匹配范围**：节点名称 + 描述，子串匹配、大小写不敏感。
- **导航**：`Enter` / `↓` 跳到下一个命中，`↑` 上一个，`Esc` 或点击 ✕ 关闭；
  也可直接点击列表项跳转。关闭搜索同时清除命中高亮，但相机留在原地。
- **高亮**：命中的节点整体标为金黄色，当前项为深橙红色；导航时相机自动飞向当前
  项，关闭搜索后相机留在原地。
- **列表**：显示每个命中的色点（类目色）、名称与描述（命中文字标橙），计数显示
  「当前第几 / 共几个」；命中极多时列表只渲染前 100 条，计数仍显示真实总数。
- **与图例联动**：图例中隐藏的类目不参与搜索；搜索开着时切换图例，命中列表与
  高亮实时更新。
- **与聚焦模式联动**：「隐藏」聚焦模式下，命中的节点豁免隐藏——找到了就该看见。
- **会话级**：不写盘、不置脏、不进撤销栈；切换文件后自动关闭（旧图的关键词对
  新图没有意义）。

大图中先搜索再定位，比手动旋转平移快得多。

### 4.7 聚焦模式

属性面板中的「聚焦模式」三态选择，适合在稠密大图里只看局部、不被整体密度干扰：

| 模式 | 效果 |
| --- | --- |
| 关闭 | 全图正常显示 |
| 灰化 | 点亮焦点节点「跳数」内的邻域网络，其余节点、连接（连同标签）退为浅灰背景 |
| 隐藏 | 邻域外的节点与连接**直接隐去**，画布只剩子网（图内搜索命中的节点仍会显示） |

- **跳数**：邻域半径，1–3 可选，默认 2。注意 3 跳在大图上可能覆盖整个连通分量
  （彼此连通成一片的全部节点），重新变成看纹理。
- **焦点选择**：开启时优先聚焦当前选中的节点；没有选中则自动选取「连接数最多的
  节点」（并列取节点大小更大的，再并列取先出现的）。开启后**单击任意节点即切换
  焦点**。
- **焦点失效**：焦点节点被删除时自动回退到默认焦点；全图删空则恢复正常显示。
- **相机**：开启时自动取景邻域，关闭时恢复开启前的视角，不会抢走你已调好的构图。
- **跨文件保持**：聚焦模式同样不写盘，但**切换文件后仍保持当前模式**，并自动
  聚焦到新图的默认焦点——大图打开的第一眼就是可读的局部网络，而不是一片纹理。
  应用重启后恢复「关闭」默认。

### 4.8 3D 画布操作

| 手势 | 效果 |
| --- | --- |
| 左键拖拽 | 旋转视角 |
| 滚轮 / 中键 | 缩放 |
| 右键拖拽 | 平移 |
| 单击节点 | 选中并在侧边栏打开节点表单；节点选中态最多保留最近 2 个（供创建连接） |
| 单击连接 | 选中并在侧边栏打开连接表单 |

- 画布底部有操作提示文案；鼠标悬停节点显示「名称：描述」，悬停连接显示连接名
  （需开启「悬浮显示连接名称」）。
- 打开文件时做一次初始取景；**布局稳定后不会自动取景**，编辑与布局调整不会打断
  当前视角。想重新框住全图，点属性面板的「复位视图」。
- 编辑后已布局的节点保持原位（新节点加入不导致全图跳动）。
- 选中态颜色随主题：浅色主题下选中节点/连接显示为黑色，深色主题下为白色；图内
  搜索命中为金黄色、当前项为深橙红色（见 4.6）。
- 超大图（2000 节点以上）会自动加快布局收敛，减少卡顿等待。

### 4.9 主题切换

设置弹窗（首页左下角「设置」按钮、图表页左上角菜单底部「设置」）中的「主题」
三选一：

- **跟随系统**：随系统主题自动切换，系统改动实时生效
- **浅色 / 深色**：强制固定，不随系统变化

选择即时生效、会被记住，下次启动保持。同时打开多个窗口时，在任一窗口切换，其余
窗口同步跟随。深色模式下 3D 图谱的背景、连线、标签与高亮配色整体配套切换，窗口
原生标题栏颜色同步；导出图片的水印颜色跟随当前主题（导出即所见）。

### 4.10 类目与颜色

- 类目色由 20 色调色板按**名称哈希 + 顺延占位**分配：同一套类目集合永远得到同一
  分配（保存重开、多窗口一致），同名类目永远同色；类目数不超过 20 时保证零撞色。
- 颜色是展示层推导的，不写入 `.xk` 文件。
- 新增类目可能使顺延链重排、**其他已有类目换色**，属预期行为；删除全部同类节点
  后该类目从图例消失。
- 图例（画布左上角）点击切换类目显隐，隐藏的类目显示为删除线 + 半透明；两端
  节点任一隐藏时，相应连接一并隐藏。

## 5. 快捷键一览

| 快捷键 | 动作 | 备注 |
| --- | --- | --- |
| `Ctrl+S` | 保存 | |
| `Ctrl+Z` | 撤销 | 焦点在输入框时不触发 |
| `Ctrl+Y` | 重做 | 焦点在输入框时不触发 |
| `Insert` | 创建节点 | 焦点在输入框时不触发 |
| `Delete` | 删除节点/连接 | 删除**最后点击**的对象（点击另一方时旧的选中态作废）；焦点在输入框时不触发 |
| `Ctrl+F` | 图内搜索 | 任何位置都触发（包括输入框聚焦时，浏览器惯例） |
| `Ctrl+R` / `F5` | 刷新 | **被禁用**（刷新会丢失未装载完的图表数据） |

## 6. `.xk` 文件格式

`.xk` 是 UTF-8 编码的 JSON，结构如下：

```json
{
  "version": 2,
  "title": "图谱标题（可选，首页卡片标题；缺省用文件名）",
  "description": "图谱简介（可选，属性面板「图谱简介」编辑的内容）",
  "nodes": [
    { "name": "GDP", "des": "…", "symbolSize": 50, "category": "宏观经济" }
  ],
  "links": [
    { "source": "GDP", "target": "CPI", "name": "传导", "des": "…" }
  ]
}
```

- 节点以 `name` 为唯一标识；`links` 的 `source`/`target` 引用节点名。
- `symbolSize` 取 1–100；`category` 缺省视为空字符串类目。
- 同一对节点允许多条连接（界面不提供创建入口，手工编辑或内置示例可能携带）。
- 手工编辑后若 JSON 非法、缺少 `version: 2` / `nodes` / `links`、或连接引用了
  不存在的节点名，文件会被判定损坏而无法打开；修改前建议先备份。
- 早期（v1）格式的旧文件不再支持。
- 内置示例（`examples/` 目录，如 `金融.xk`、`中国哲学.xk` 等 200 余张）可直接
  打开体验。

## 7. 数据安全机制

### 7.1 自动保存与原子写入

- 有未保存修改且已有文件路径时，每 60 秒自动保存一次，全程静默、不打断编辑。
- 保存采用「临时文件 + 改名」的**原子写入**：写入中途崩溃/断电/磁盘满时，目标
  文件要么是旧内容、要么是新内容，不会留下截断的半个 JSON。
- 极端情况下保存目录可能出现 `.tmp-` 开头的残件（应用崩溃时机不巧遗留），确认
  文件本身正常后可手动删除。

### 7.2 外部修改冲突检测

文件被其他窗口或外部程序（编辑器、同步盘等）修改后，再保存会被拦截并提示
「文件已被其他窗口或外部程序修改」——直接覆盖会丢失对方的修改。此时请使用
「另存为」换一个路径保存你的版本；冲突解决前自动保存暂停，不会反复弹错。

### 7.3 内置示例写保护

`examples/` 目录内的示例是内置资产，任何途径都不允许写回：

- 图库双击打开的示例走**副本语义**（保存必弹「另存为」，编辑的始终是自己的副本）；
- 通过「打开文件」对话框选中示例文件，同样按副本处理；
- 「另存为」时选择示例目录内的路径会被拒绝（「示例文件不允许修改，请选择其他
  位置保存」）。

### 7.4 关闭保护

关闭未保存的文件或窗口前，一律弹出三选一确认：**保存 / 放弃 / 取消**。确认框
模态于触发它的窗口，多窗口并排时不会误关别的窗口。选择「保存」时只有保存成功
才会关闭，失败则留在当前页面。

## 8. 常见问题

**打开文件提示「文件已损坏或不是有效的 XKnowledge 文件」**
JSON 语法错误，或不是 v2 结构（缺少 `version: 2` / `nodes` / `links`）。可手动修复
JSON 后重试；早期（v1）格式的旧文件不再支持。

**打开文件提示「文件结构不完整…」**
括号里会注明缺失项，常见为连接引用了不存在的节点名（悬空连接），补齐节点或删掉
该连接即可。

**保存时提示「文件已被其他窗口或外部程序修改」**
文件在别处被改过，直接覆盖会丢失对方的修改。请用「另存为」换一个路径保存；
在此之前自动保存已暂停，不会反复弹错。

**3D 视图初始化失败（显卡驱动异常？）**
WebGL 不可用。侧边栏的编辑、保存功能不受影响，可正常使用；建议更新显卡驱动后
重启应用。

**保存目录里出现 `.tmp-` 开头的文件**
自动保存采用「临时文件 + 改名」的原子写入，应用崩溃时机不巧可能留下残件，确认文件
本身正常后可手动删除。

**提示「该文件已在打开的窗口中」**
同一文件已在某窗口编辑，应用会自动置前那个窗口（最小化时自动还原），避免两个
窗口互相覆盖。

**大图卡顿怎么办**
依次尝试：关闭「显示小节点名称」（超大图会自动按预算封顶标签数量）、用图例隐藏
暂不关心的类目、开启聚焦模式只看局部、用 `Ctrl+F` 搜索定位代替手动旋转平移。

**误关了窗口，还能找回修改吗**
撤销/重做历史不落盘，关闭窗口即清空。但分两种情况：文件已有路径且此前有编辑的，
自动保存至多间隔 60 秒，未写盘的修改只会是最近一分钟内的——重新打开文件检查；
从未保存过的新建文件（无路径）一旦放弃，修改无法找回。

**示例图谱打开后改了内容，保存不进去**
内置示例是只读资产，编辑的一直是副本：`Ctrl+S` 会弹出「另存为」，选一个
examples 目录之外的位置保存即可。

**新建的类目让其他类目变了颜色**
类目色按名称哈希在 20 色调色板中顺延分配，类目集合变化可能引起重排，属预期
行为；不影响已保存的数据（颜色不写入 `.xk` 文件）。
